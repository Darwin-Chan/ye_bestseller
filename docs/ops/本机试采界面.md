# 本机试采：界面使用说明

2026-10-08 · 实施票 02。使用现有采集界面，不新增程序。

## 进入与开始

1. 正常打开采集界面，默认仍是正式采集；纯汇总机默认不能正式采集。
2. 点击顶部“进入本机试采”。开始、过程、结果页持续显示 **本机试采，不共享**，
   使用下文所述稳定隔离数据库位置。角色、机器编号、正式配置、凭据和浏览器 profile 不变。
3. 在开始页手动勾选本机 CSV 中启用的店铺，再开始采集。试采不受周计划份额限制，
   不需要本周计划，也不生成、同步、发布计划或写正式补采账。店铺页数和预算沿用
   CSV/现有配置，不使用共享计划页数。界面启动既有采集子进程，显式传入
   `--local-trial --config <正式配置绝对路径> --limit-shops <所选范围>`。

缺清单、未知或停用店铺、空范围、隔离空间不可用会明确拒绝，不回退正式库，
不自动替换店铺、不修改共享清单。有效但仅含表头的 CSV 可用于查看历史和续跑，
不能用于新开空范围轮次。命令行选项见 [本机试采命令行](本机试采命令行.md)。

## 过程、暂停、中止和续跑

- 过程页显示本次试采轮次与进度；结果页查看试采库存/图片和终态，不混入正式观测。
- 暂停发送现有停止请求；请求未成功不会假装暂停。停止仍在进行时不能切换模式。
- 同日暂停后点续跑，沿原进行中轮次及保存的店铺范围继续；续跑不重新提交新店铺范围。
  即使 CSV 启用项改变，也不静默换店。改范围拒绝，跨日不续跑旧轮次。
- 中止作用于对应试采身份和轮次，终态沿已有规则；目标不明时拒绝，不猜测进程。
- 命令行启动的试采或窗口重开后的试采，在显式进入试采后也能识别、监控、暂停和中止。
  机器采集锁忙但身份无法核验、PID 身份不符或另一模式运行时，拒绝危险操作。
- 正式采集与试采共用机器级采集锁，界面沿用单实例机制；不能同时采集，运行中不能
  静默切换显示/控制目标。窗口关闭沿原有关闭规范，本功能不重定义关窗行为。

## 历史与隔离

试采稳定落在正式 `data_dir` 上一级的 `local-trial/`，不是每次新建数据集。
库存、图片、原始页面、轮次和停止请求使用同一试采空间；子进程日志为
`local-trial/logs/run.log`，试采 GUI 查询/控制日志为 `local-trial/logs/gui.log`。
准备失败或空间与正式路径重合时拒绝，不用正式空间兜底。

再次进入保留历史。试采自身的完整成功观测按既有规则同日去重，因此重复采集可能
跳过已经采到的商品；正式同日库存不会挡试采。不提供清空、重新试采、强制重采或
转正式入口，不应为了测试删除历史。无运行/停止任务时可显式返回正式采集。

## 正式功能仍照常

试采只采集，不运行试采销量分析、不产生试采判断集，也不导出试采 raw 包或上传图片。
交换台和销量分析仍使用正式配置/正式库，汇总机仍收取其他机器的数据；
**正式销量分析产生的判断集仍按共享通道发布和收取**，不是关闭共享来实现隔离。
不要手工把分析或交换配置改指向试采数据库。

本票验证使用真实 SQLite、采集编排与本地 Git，浏览器/网络/进程边界使用替身；
实际 HTML 使用离线临时 Edge profile 验证，不自动运行真实网站采集。
