# 本机试采：命令行使用说明

2026-10-08 · 实施票 01。GUI 显式试采入口与跨入口监控已由 02 接线，见 [本机试采界面](本机试采界面.md)。

## 启动

在程序源码目录运行（店号换成本机清单里启用的 `shop_key`）：

```powershell
python run.py --local-trial --limit-shops A01 --pages-per-shop 1 --max-detail 10
```

- 使用现有配置；非默认配置可加 `--config <配置文件>`，清单可用 `--shops <CSV>` 覆盖。
- 需要本机 CSV 清单，列与 `config/shops.example.csv` 相同；新开轮只选启用店。
  未点名店铺时，续跑当日进行中轮次的原范围；即使原店铺后来全被停用或移除，
  仍按轮次记录续跑（清单文件及有效表头必须保留）。没有进行中轮次则选清单全部启用店。
- 缺清单、新轮空范围、显式选择未知或停用店铺明确拒绝，不自动换店。显式点名不同于当日进行中
  轮次的范围仍拒绝。CSV 中的页数和现有预算、节流、人工介入机制继续生效；
  显式 `--pages-per-shop` 覆盖 CSV 页数，不采用共享计划页数。
- 机器编号、`merge_only` 角色、凭据与浏览器/profile 不变。**未加 `--local-trial`
  时纯汇总机仍拒绝正式采集，`--ignore-plan` 也不能绕过角色闸门。**
- 试采不拉取、生成或发布计划，`--ignore-plan` 在试采中不参与选店、不写补采账。

## 稳定落点

由正式 `data_dir` 的上一级目录派生，不是每次运行创建一套：

| 内容 | 路径 |
| --- | --- |
| 库存、图片字节、证据、轮次、采集身份与停止请求 | `local-trial/data/bestseller.db` |
| 原始页面存档 | `local-trial/data/raw_pages/` |
| 截图预留落点 | `local-trial/data/screenshots/` |
| 运行日志 | `local-trial/logs/run.log`（轮转保留三份） |

启动会打印绝对数据库与日志路径及“本机试采，不共享”。当前真实采集流程不主动生成
截图；沿用现有产物，不为本票新增截图功能，截图配置同样隔离。

试采空间与正式数据、日志、交换区、浏览器 profile、配置/清单、正式分析数据库、
判断缓存、人工决定账本或报告目标重合时拒绝；子目录符号链接/junction、硬链接文件
也拒绝，避免绕过路径隔离。空间不可用或数据库无法准备时明确报错，**不回退正式库**。
预检不是对运行时恶意改动文件系统的沙箱；不要在采集中更换目录链接或重配消费者路径。

## 续跑，不清空

- 沿用同一试采历史。同日同范围进行中的轮次续跑；同日改范围拒绝（退出码 3）。
- 试采自己的完整成功观测触发同日去重，跳过不产生新的库存成功或图片证据。
  正式库的同店同日成功不阻止试采。
- 人工暂停/中止、当日截止线、跨日收尾和终态沿用现有底层机制。
  本票不新增命令行停止命令；GUI 暂停/中止与跨入口停止目标见界面说明。
- 不提供“重新试采”、清空、强制重采或转正式数据；不能为了重测而删除历史。
- 正式采集与试采共用机器级采集锁，已有采集运行时拒绝并返回既有专用退出码。

## 共享边界

试采仅运行采集：不接入正式分析，不产生试采判断集，不导出 raw 包或上传图片。
派生的试采上下文不能传入导出/交换入口；不要手工把正式分析或交换配置改指向试采库。

普通交换和销量分析继续读取正式配置、正式库。纯汇总机照常汇总其他机器库存，
**正式销量分析产生的判断集仍按原通道发布与收取**，本功能没有关闭判断集共享。

## 验收边界

自动测试使用真实 SQLite、真实采集编排的浏览器替身、图片 HTTP 替身、本地裸 Git
和假图片存储；不访问真实网站、远程 Git/COS 或真实模型。实施不自动替使用者启动采集。
