# 库存快照历史工单索引

早期库存快照规格、IS 系列工单及原始问题文档保留在本机忽略的历史工单目录中，不随公开仓库发布。此次公开名称调整保留原始材料及工单编号，通过本索引定位本机证据。

- 规格：历史库存快照功能目录中的 spec.md。
- IS-31：滑块人工处理观测记录，文件名为 31-is-31.md。
- IS-42：库存快照提交相关工单，按 IS-42 编号查阅。
- IS-55：停止与清理相关工单，文件名为 55-is-55.md。
- IS-57：主动停顿验收依据，文件名为 57-is-57.md。
- 原始问题文档：同功能目录的 archive 子目录。

在仓库根目录执行以下只读命令，可按唯一的 IS-55 文件名定位历史功能目录；其上两级目录即规格和 archive 所在目录。当前机器未保存历史工单时，这些材料不可用，不应视为已随仓库提供。

```powershell
rg --files --hidden --no-ignore .scratch -g 55-is-55.md -g '!sandboxes/**' -g '!inbox/**'
```
