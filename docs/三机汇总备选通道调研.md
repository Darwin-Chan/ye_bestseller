## A. Syncthing（P2P 文件夹同步）

**三台都无公网 IP：能工作，无需任何端口映射。**

- 官方文档：中继（Relaying）默认启用，仅在两台设备无法直连时使用；经中继的速率**远低于**直连。
  端口转发/UPnP 只是"提高直连成功率"的可选项；不做时"Relaying may work well enough to get devices
  connected and synced, but will perform poorly"。只有一方做了端口转发，双方都能受益。
- 传输**端到端加密**："the relay only retransmits the encrypted data"；中继运营者可见 IP、设备 ID
  与流量大小（元数据），看不到内容。中继池由社区志愿者贡献，任何人可自建（`strelaysrv`）。
- 实践坑（官方 FAQ 单列）：Windows 把网络配置文件设为"公用"会阻止直连、**强制走中继**；改成"专用"恢复。
  **中国大陆对公共中继/发现服务器的可达性与速率：未核实**（兜底：自建中继，或写死设备地址）。

**同步冲突：产生"冲突副本文件"，脚本按文件名识别。**

- 较旧版本被重命名为 `<文件名>.sync-conflict-<日期>-<时间>-<modifiedBy>.<ext>`，两份都保留；
  且冲突副本本身会同步到所有设备（官方提醒要额外防护，别再当冲突处理）。
- 脚本识别 = 遍历匹配 `*.sync-conflict-*`；官方另有 REST API 与 `--audit` 事件日志可做监控。
- 官方明确：Syncthing **不是备份工具**（改动/删除会传播到所有设备）。

**Windows 常驻与自启**：无官方安装包；用任务计划程序（`--no-console --no-browser`，勾掉"超时停止"）
或启动文件夹；首次需交互运行一次放行防火墙。空闲 CPU 可忽略，扫描大目录时因全文件 SHA-256 有尖峰；
任务管理器里会看到两个进程（父子的官方设计）。

**拓扑**：默认全互联，每台手工添加另外两台的设备 ID（双方都要加）；可选 Introducer 自动引荐新设备。

**承载"结构化包 + 几百 MB 图片"：可。** 增量传输是块级的；官方 FAQ 给了"大文件夹手工预热"流程
（先物理拷贝到对端，再用**相同 Folder ID** 建文件夹，已存在文件不再重传）——正好适配首次 150 MB 图片包。
MPL-2.0 开源免费。

## B. 网盘族

### B1 坚果云（首选兜底）

- 脚本化：官方 WebDAV，`https://dav.jianguoyun.com/dav/`，账号 + **应用密码**（非登录密码）。
- 免费额度（官方帮助原文）：每月上传 1GB、下载 3GB，耗尽后当月停止同步、次月恢复。
- 限制：**单文件上传上限 500MB**；免费用户 **每 30 分钟不超过 600 次请求**（付费 1500）；单次请求文件数 750。
- 算账（本项目量级）：每台每月上传 ≈ 100–200MB、下载 ≈ 400MB（两台他人的包 + 部分图片），
  **免费额度装得下，余量 3–5 倍**，首次 150MB 图片包也在内。
- **机制性结论：git 不支持 WebDAV 协议**，它只能当"对象存储"，不能当 git 远端。

### B2 OneDrive

- 免费 5GB（+15GB 邮箱）；API 即 Microsoft Graph 文件 API，需在 Microsoft Entra 注册应用
  （免费，账户类型可选含个人 Microsoft 账户）；限流为 429 + `Retry-After`；大文件走 upload session。
- 失败模式：5GB 上限（18MB 周包 + 图片很快见底，只能当小包替身）；**国内可达性/速率未核实**。

### B3 阿里云盘

- 官方开放平台存在（`openapi.alipan.com`，文档在语雀），但**文档正文未能直取**；入驻/鉴权/免费容量
  均为二手转述，标**未核实**。判定：不作依赖。

### B4 百度网盘（仅人工/兜底）

- 个人认证可建 **1 个**应用；普通用户分片固定 4MB、单文件上限 4GB。
- 官方 FAQ 原文：**浏览器场景超过 50MB 的文件不可下载**；免费账号下载被限速；**接口频控不公开**。
- 判定：可以传、不宜指望自动取回。只作最后手段。

## C. 在线表格承载"周计划"

**飞书多维表格：能当通道，也是本族唯一可行者。**

- 鉴权：建免费飞书企业（自己是管理员）+ 企业自建应用拿 `app_id/app_secret`，
  `POST /open-apis/auth/v3/tenant_access_token/internal` 换 token（最长 2 小时）——**一个 POST，无 OAuth 跳转**。
- 读写：多维表格 v1 记录接口齐全；批量新增 **50 次/秒**、单次 ≤1000 条；调用前把应用**加为表格协作者**。
- 免费版可用 API（官方频控表含"基础版自建应用"一列）；行数：基础版 2,000 行 + 免费领取 1.8 万行。
  周计划几 KB/周 → 余量在 3 个数量级以上。
- 注意：API 无事务语义，**多台同时写同一表**需自写"读-改-写"防竞态——若计划只由一台发布、其余只读，则无此问题。

**金山文档 / 腾讯文档：个人版不成立。** 金山文档 WebOffice APPID 帮助中心原文"需要以公司身份注册，
暂未开放个人用户注册"；WPS 开放平台需先完成"服务商认证"；腾讯文档开放平台按主体类型注册并逐应用审核。
（注册页为 JS 渲染，正文未直取——**结论按官方门槛描述判定**。）

## 总体建议

主通道（git 私有库 + 对象存储）之外，**A 与 B1 互不依赖、可同时准备**：Syncthing 负责"目录级全量交换"，
坚果云 WebDAV 负责"文件级对象交换"；两者都不可达时，**周计划单独走飞书多维表格**；
百度网盘仅作最后兜底；阿里云盘/OneDrive 不作依赖或仅作小包第二兜底。
