# 0040. 同款分组改为带约束的相关聚类：只判边界对、判定带分数下限

- 状态：已接受（2026-09-23）
- 日期：2026-09-22（草案 2026-09-22 起草；2026-09-23 按 E2/E6 实测修订后接受）

## 背景

销量分析的「同款确认」现在是一条链：召回给每个商品取分数最高的 `candidates`（现为 6）个
邻居（`candidate_pairs`）→ 每个召回对交模型判同款（对级判断，缓存带署名）→ 装配时把一个
商品放进某个组，当且仅当**它与组内每个成员都有一条正判断边**（`_suggest` 尾部的
`all(matches(...))`）。也就是说：**组是完全图（团），没有传递闭包，没判过的对与判否的对
效果一样**。

**2026-09-22 夜的标定跑**（区间 [09-21, 09-22]，792 个商品；跑完的清单与分组见判断缓存的
`recommendations`，实测小结在 `.scratch/bestseller-analysis/E2标定实测.md`，方法依据
[同款分组判定效率调研](../research/同款分组判定效率调研.md)）把这条链量成了实测：

- 召回 k=6：**3803 对**；判定 **3786 对**；**正边率 ρ = 8.5%**（323 条正边）。
- **分数→同款率**：得分（共享 token 数）≤3 的 1620 对里**一条正边都没有**（占判断预算
  42.8%）；4 分 0.2%、6 分 1.3%、8 分 7.9%、10 分 28%、12 分 44%、**15 分 84%**。
- **召回截断不是瓶颈**：未召回且分数 ≥5 的对 1602 条，按同分段的实测率外推只值 ≈21 条
  正边（现有 323 条的 6%）——单轮硬撑大团要 `candidates ≥ 17`（440 商品复算：k≥17 才出现
  14 团；3000 商品 ≈ 4.3 万对、约 20 小时），更不经济。
- **正边图**：176 个 ≥2 人分量、最大分量 **8**、最大团 **5**、k-core 4——调研担心的
  「低正边率下渗流成巨分量」没有发生（真实正边成簇）。
- **现状团装配**：558 组、183 个 ≥2 人组（137×2 + 43×3 + 1×4 + 2×5）、417 个商品在组内。
  这批数据里真实同款簇本来就小；8–14 人组的场景要等 12 店全量数据才验得了。
- **款式签名（E6）实测否决**：240 个商品的结构化签名、780 对对照——按字段一致数排序的
  精度被现有召回分数全面压过（签名 top-100 精度 58% vs 分数 top-100 86%；在分数 ≥7 的
  子集里叠加签名过滤与同预算下分数单独排**净增为零**）。每图一次的签名调用不值这个钱。

决定本条的是目标的表述：**在尽量少的判定下得到尽量多 80% 正确的组**，允许「模型一轮 →
人工一轮 → 模型再一轮」。现状装配把「没判过」当成「判否」，等价于要求把每对都判完才允许
成组——与目标函数方向相反。

## 决策

**分组语义从「完全图装配」换成「带人工约束的相关聚类」；判定仍以对级判断为单位，只判
边界对，并给判断加一条分数下限。**

1. **相关聚类，缺边当未知。** 装配的代价函数只对**已判**的边计费：判为同款却被分开、
   判为非同款却被并在一起，各付代价，且**假阳更贵**（把不同款并进一组的代价高于把同款
   分开，负边分歧权重 > 正边分歧权重，比值可调）；**没有判断的边不参与代价**——「没判过」
   不再等价于「判否」。簇数不预设（1 到 n 都可能）。
   依据：Bansal/Blum/Chawla 2004（相关聚类；±1 权重与噪声下的结果）、Demaine/Immorlica
   2003（缺边当无信息权重）、Makarychev 等 COLT 2015（稀疏 + 带噪信息）；主源与查阅层级
   见调研 §3 路线 3 与来源表。**离线回放（实测数据）**：负边权重 w=1 时最大组 5→7、
   正边覆盖 89.8%→94.1%、纯度 100%→98.1%；w=2 时纯度 99.3%、覆盖 91.6%；w≥4 退化成
   团装配。**验收线「纯度 ≥80%」由此变成可调参数**：权重取值由人工确认过的参照组定
   （见「验收判据」第 4 条），不写死在本条。

2. **人工决定是硬约束。** 账本语义照旧、不新增表：已确认的同款组（成员两两 must-link）、
   独立确认（该商品自成一组，不与别组并）＝ must-link 类约束；排除对 ＝ cannot-link。
   相关聚类只在约束允许的划分里求最优；**约束与判断边冲突时约束赢**——人说过的话不被
   模型边翻掉。（must-link 传递、cannot-link 不传递，页面文案照此写。）

3. **判断预算下限：得分低于下限的对，不交模型判断。** 依据是实测：≤3 分的 1620 对占
   42.8% 的判断预算、产出 0 条正边；下限取 4 可省 43% 调用、损失 ≤1 条正边，取 5 省 55%、
   损失 ≤3 条（同分段实测率外推）。
   - **这是预算规则，不是同款判定**：被下限挡下的对保持「没判过」= 未知，不产生任何边
     ——「特征只做召回、从不决定同款」的不变量原样成立。
   - **可调、可回退**：配置键 `matching.min_score`（默认 4，见 `analysis.example.toml` 与
     README）；调低只影响之后的运行，已判的对照旧命中缓存。下限与得分刻度绑在当前的
     召回特征规则上，换特征规则时要重新标定。
   - **上限与下限并存**：每商品召回仍取 `candidates` 个（下限只管判不判，不管召不召）。
   - 跨机「分组对一眼一致」的验收要求各机同值（与 candidates、权重同规）。

4. **判定单位仍是对级判断，模型只判边界对。** 不引入「每图一次的款式签名」这类中间层
   （E6 实测否决，见背景；将来若出现判别力更强的结构化证据形态，另写 ADR 再议）。
   - **首轮**：判召回对里分数 ≥ 下限的那些（现状的形态，加下限）。
   - **后续轮只判边界对**：与已确认组内 ≥1 成员有正边、但不满足全员正边的商品 × 该组
     成员的对；跨提议组的对；人工拆分处的对。均匀全量判定不再是默认形态。

5. **多轮协议写死触发与停止**（模型一轮 → 人工一轮 → 模型再一轮）：
   R1 模型判召回对（带下限）→ P 提议（相关聚类产出提议组）→ H1 人工确认/拆分（产出
   must-link / cannot-link 锚）→ R2 模型只判锚周边界对 → H2 人工只看变化。**停止**：
   一轮之后归属变化 < 5%，或到达预算上限，或人工预算耗尽——三种都停在「已保存的草稿/
   账本版本」上，随时可停。**预算上限**：每轮边界判定数 ≤ 首轮判定数的 50%，超限的分量
   转人工、不硬补（依据：低正边率下无结构补边会渗流，实测虽未发生但按上限兜底）。

6. **装配必须确定性。** 同一判断集 + 同一账本 + 同一配置（含下限与权重）⇒ 同一分组；
   启发式里的随机要素必须是固定种子或确定性过程，权重参数随分析程序版本走、不进各机
   自己的配置。这是 ADR-0039「两台机器在同一批数据上分组对一眼一致」验收的前提。

7. **提议落回既有入口。** 提议组走 `update_candidates` 的既有位置（页面上的候选组与
   「疑似归组」提示）；`recommendations` 表沿用 ADR-0039 的决定（只写不读、不搬）。

## 没动的（挂账维持）

- **召回算法与特征仍在规格留白区**（`.scratch/bestseller-analysis/spec.md`「候选召回算法不在
  本规格固定」）：candidates 配置照旧；**自适应扩边/加大 candidates 不做**——实测未召回且
  分数 ≥5 的对只值 ≈21 条正边（6%），不值那份预算。特征升级另议（本机样本只有 4–7 对
  弱标注，不足以验证收益，调研 §2.6）。
- **「特征只做召回、从不决定同款」的不变量不动**：决策 3 的下限是预算规则（不判≠判否），
  不是阈值判定；将来若要做阈值分桶成组，必须另写一条 ADR 明写例外。
- **款式签名不做**：E6 实测它与现有召回分数比没有净增价值（背景）；已花的 240 次试点
  调用是验证成本，不留实现。
- **判断集跨机共享（ADR-0039）不动**：票 03–08 照旧；本条不新增任何要搬运的表。
- **三个零风险提速（星形批量、并发、并列带帽扩边）不进本条**：属实现细节与配置，将来要
  做不需要 ADR。
- **平台图搜不做**：1688 开放平台的图搜接口准入门槛在「服务市场分销工具商」，且引入官方
  通道不改变本项目的合规定性（调研 §3 路线 10）。

## 结果与代价

- **收益**：判定预算先省 43–55%（分数下限，实测）；8–14 人组不再被团上限挡住（相关聚类
  的形态）；人工从「逐组确认」变成「确认锚点 + 只看变化」；80% 纯度变成可调可验收的参数。
- **代价一：页面语义要跟着换。** 「组」的含义从「成员两两判过」变成「由已判边与人工约束
  推出的划分」；确认页的「匹配唯一同款 / 多组同款 / 疑似归组」文案与行为要同步改（待确认
  组仍要人工确认后才保存，这条不变）。被下限挡下的对在页面上属于「未召回候选」一类，
  文案要说得清（它们不是判否）。
- **代价二：相关聚类是 NP-完全问题**（BBC 2004），实现只能取近似启发式（贪心 pivot / 局部
  搜索）；近似质量与权重敏感，需要参照组数据定参。
- **代价三：上限受召回产出限制。** 实测正边只有 323 条（ρ=8.5%），相关聚类相对团装配的
  增益因此有限（覆盖 +4.3 点）；它的真实价值要等 12 店全量数据（同款簇更大、团上限才会
  真的咬人）。判断缓存在积累：届时重跑，已判的对零调用、只付新增。
- **标定已做**（2026-09-22 夜：3803 召回对、3786 判定、两轮重试后剩 17 对判不动；另有
  240 次签名试点）；**仍缺人工确认过的参照组**——80% 纯度验收要对它算，属实施步骤。
- **挂账（要单开票）**：① 相关聚类装配与页面语义改造；② 人工确认轮（产出参照组）；
  ③ 12 店全量数据后的重跑与权重定参。

## 验收判据（草案，落地时进票据）

1. **缺边不阻塞**：构造「A1 与 A2/A3 未被召回、与 A4–A6 判过同款」的用例——新装配下 A1
   与它们同簇（或列为边界交人工），不再因缺边自成一组。
2. **硬约束优先**：已确认组不被拆、排除对不被并；约束与判断边冲突时约束赢。
3. **确定性**：同一判断集 + 同一账本 + 同一配置（含下限与权重），两次装配逐组一致；
   两台机器同判断集、同下限下分组对一眼一致（与 ADR-0039 的验收同规）。
4. **纯度-预算口径**：在人工确认过的参照组上，纯度 ≥80% 的前提下最大化入组商品数，如实
   记下判定次数与人工分钟；与现状装配在同批数据上对照（8 人以上组数、覆盖率）。
5. **分数下限生效**：同一份判断数据上，加下限后判对数省 ≥40%、正边数损失 ≤1%；被挡下的
   对在页面上不显示为「判否」。
6. **预算上限生效**：边界判定 ≤ 首轮 × 50%；超限的分量转人工并有记账。
