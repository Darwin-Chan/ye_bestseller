# 原始数据来源与当前采集名册解耦，保留历史生产者

状态：已接受（设计边界），2026-10-24；尚未实现。

三机核查发现，原始数据接收只遍历本地已有来源，容易把未接入的机器漏掉；当前采集名册也无法表达 m4 等退役采集机留下的真实历史。用户确认本轮加入共享批准的原始数据来源清单、持续核对与自动接入，并覆盖全部现存且可恢复历史。

原始数据来源清单与当前采集名册、判断来源清单分别表达，包含当前及历史采集数据生产者。机器暂停采集或转为纯汇总，不自动移除其历史来源；已有克隆核对地址并保留脏现场，不自动删除、改址或重建。

代价是新增一份需要维护和保鲜的共享事实；收益是接收范围可核对、转角色不丢历史通道，而不是让“本地恰好有什么目录”决定该收谁。清单由 m4 统一维护，经可信 owner 与批准范围核对后发布到共享 plan 库；查询不完整、来源减少或改址时保留上一版并告警，不自动删除既有克隆。具体实现和退役确认流程仍待实施设计。

决策与验收范围见 [恢复计划](../design/exchange-recovery-plan-2026-10-24.md)，核查证据见 [三机报告](../reviews/三机交换台与数据完整性核查-2026-10-24.md)。
