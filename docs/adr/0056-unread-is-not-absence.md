# 0056. 读不成不得降级为否定事实（外部事实探测的失败方向）

- 状态：已接受（2026-10-13）
- 日期：2026-10-13

## 背景

这是同一条纪律的第二次出现。

第一次在 **issue 05**（2026-10-12，提交 `25e966e`）：git 通道的三处读路径把任何失败都吞成
「就是没有」，其中 `head_matches_upstream()` 还会把**读不成**判成「两端一致」——而它是接收侧
「来源库有没有被人动过」的放行判据，失败方向正好反了。当时的修法是：只在认得的 git 措辞上回
空值，其余失败一律抛出同形的错误。

第二次在 **issue 15**（2026-10-12 m2 现场）：开抓前的浏览器事实核对（一条 PowerShell 枚举全部
进程命令行与全部监听端口，硬上限 12 秒）在冷态偶发超时；超时异常被最外层一个宽 catch 接住，
折成一个 `unknown` 事实，`status()` 再把它一律映射成「不许开」。于是「我读不出来」和「我看到
有人占着」在用户眼里变成同一句话——现场是空城，程序却请他「自行关闭专用 Edge」。随后界面每
2 秒同步轮询同一条 12 秒探测、排队堆积，16:50:08 被判无响应、16:51:41 被系统杀掉，采集子进程
从头到尾没有启动。

两次的形状一样：**一个外部事实的「读不成」被当成了这个事实的否命题**。

## 决策

**一、外部事实的输出按「读到的事实」与「读不成」两分，只有读到的事实可以拦人。**

- **读到的事实**：探测本身成功，读出来的东西自己构成结论。浏览器事实这一档是 `occupied`
  （有进程明确带这个专用 profile）、`port_busy`（调试端口被听）、专用目录里存在 Chromium 锁
  文件、目录文件被别的实例独占持有（`ERROR_SHARING_VIOLATION`——共享冲突本身就是「有实例在跑」
  的证据）。这些判据不依赖那条超时缰绳，照旧拦开轮，文案照旧。
- **读不成**：探测自己失败——超时、返回码非 0、正文解不开、权限不足（`ERROR_ACCESS_DENIED`）、
  非 Windows 主机。它们如实报告、留下痕迹，**不构成拒绝**。
- 旧代码里这两种共用一个宽 catch、一段文案，而且 `CreateFileW` 失败后**没有取最后错误码**——
  「共享冲突」与「权限不足」在代码里根本分不开。分档的前提是先把最后错误码取回来。

**二、「读到了东西、但归属核不实」是第三档，也拦不住人。** 浏览器事实里的 `unknown` 指这一档：
看到了浏览器进程，但命令行读不出、profile 是相对路径、或 `--type=` 子进程找不到可读的浏览器
祖先。它确实是读到的东西，但**归属**这一步靠的是读命令行文本——软判据。软判据不该有否决权：
最终归属由开抓时的身份门判（CDP 取真浏览器 PID ＋ OS 创建时刻，见
[ADR-0025](0025-browser-session-owns-establishment.md)）。

**三、失败方向选「放行」，依据是两边的代价不对称。** 读不成的代价是**推迟一次判定**——真占用
会由下游的硬门拒绝，只是拒绝得晚一点、说得更准一点；误判的代价是**挡住一次正常采集**，而且
现场无法自查（用户照着提示做什么都没用）。宁晚勿错。

**四、例外要写明白，不许含糊：登录入口没有第二道门。** 点「打开专用 Edge」走的是一次普通
`Popen`，没有归属门兜底。放行后最坏的结果是窗口开在一个已有实例上——Chromium 自己的
ProcessSingleton 会交棒而不是双开，所以可以接受；但这是这条纪律唯一一处「放行之后没人接着拦」
的地方，改动它之前先看这里。

**五、`_unconfirmed` 不属于读不成。** 「我们启动了浏览器、却观察不到它」是我们自己的动作没有
结果，不是外部事实读不成——它照旧拦住，直到一次成功的读数看见它为止。

## 结果与代价

- issue 15 现场那条链断了：超时不再等于拒绝，界面也不再被探测拖住（探测退出同步路径，读路径
  只读快照）。
- **代价**：真的占用而恰好读不到时，流程会多走一步——拉起浏览器、被归属门拒绝，错误消息来得
  晚一点。这一步换来的是「读不到时永远不误伤」。
- **被否决的替代方案**：① 只把 12 秒放宽（治标——冷态实测 6.28 秒已经贴着上限，抖动照样越界；
  而且不解决「超时＝拒绝」这层语义）；② 维持 `unknown` 一律拒绝（现状，就是本 ADR 要修的东西）；
  ③ 读不成也放行但不留痕（下次现场再现时仍然无据可查，而这次的诊断成本正来自这一点）。
- **一条判据**：今后凡是「读外部事实」的路径，先问一句——这个失败会被拿去当否命题用吗？会，
  就必须分档。
