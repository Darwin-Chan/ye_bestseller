# 0001. 同日去重以商品编号为准

- 状态：已接受
- 日期：2026-09-11

## 背景

同日去重最初按商品名匹配：列表页先读到商品名，若同店同名商品当天已有库存就跳过详情访问。名称唯一时这很快，但同店出现同名商品时会误判。

可复现的后果：商品 11 当天已有完整库存，同店同名商品 22 只有失败记录；补采商品 22 时被同名库存挡住，一次详情都没访问就退出了待补采集合。

## 决策

- 已知商品编号时，同日去重只按商品编号判断；同店同名库存不能阻止该商品补采。
- 商品名只在列表页还不知道编号时使用，作为「暂缓访问」的预筛选；它不是商品身份，也不构成去重证据。
- 失败与不完整观测同样不构成去重证据。

## 结果

同名商品的失败记录不会再被静默丢掉。代价是列表页不能再靠同名库存省下一次详情访问，正确性换掉了那部分时间收益。

相关词汇见 [CONTEXT.md](../../CONTEXT.md) 的「同日去重」「补采」；实现见 `bestseller_monitor/dedupe.py` 与 `bestseller_monitor/pipeline.py` 的 `_capture_offer_detail()`。
