# 0059. 详情访问结果与原始页面引用统一

- 状态：已接受（2026-10-17）
- 日期：2026-10-17

## 背景

[ADR-0013](0013-detail-observation-module.md)、[ADR-0018](0018-page-to-observation-in-detail.md)、[ADR-0020](0020-detail-visit-shared-across-paths.md) 和 [ADR-0023](0023-detail-visit-returns-fresh-observation.md) 已经把点击采集与补采放到同一个详情访问 seam 上，并把页面读取放在验证之后。现在这个 seam 仍然只统一了访问顺序，访问终态和原始证据的形状还没有完全统一：

- 正常读取、读取失败、deny、晚到 deny 和人工介入后的当前页面，仍由不同结果对象或调用方私有分支表达。
- 点击路径仍有私有的晚到 deny 结果，阈值异常上的 `raw_path` 通过动态属性附加，调用方需要知道多套取证形状。
- `raw_pages` 已经是存档路径和命名的集中 adapter，但访问结果没有携带统一的最小引用，导致证据落盘与访问事实之间的连接依赖调用方拼装。

这会让两条详情路径在行为上看似共用访问 module，却仍然各自维护访问结果的解释方式，也让异常路径比普通结果更难测试和追溯。

## 决策

### 一、只深化现有详情访问 seam

详情访问结果的统一继续收在 `detail_visit`。不新增第二个跨路径 module，也不把详情观测的业务结果吸收到详情访问结果里。

`begin_detail_visit()` 继续负责取得页面和初次 guard。调用方先取得商品身份，执行同日去重、详情机会和其它详情观测前置判断，再对一次性的 `ReadyDetailVisit` 调用 `observe()`。两阶段协议保留，因为身份和业务判据必须发生在页面取得之后、实际读取之前。

详情访问结果统一表达页面取得、初次验证、可读等待、晚到验证、当前 HTML 读取和相关访问事实。`detail.capture_observation()` 继续表达解析、完整性、同日去重、重复、尝试额度、失败记录和提交结果。

### 二、结果携带可选的原始页面引用

详情访问结果可以携带一个最小的原始页面引用。引用只指向存档，不把 HTML、轮次配置、目录结构或磁盘操作传播到 guard、判据和详情观测层。

原始页面写入和命名继续由 `raw_pages` adapter 负责，并沿用 [ADR-0057](0057-intervention-archive-landing-and-boundary.md) 的命名：

- `round_N/<offer_id>.html`
- `round_N/<offer_id>.<vtype>.html`
- `round_N/intervention_<safe_shop>.<vtype>.html`

本轮不按尝试次数或时间戳新增命名。页面读取失败、写盘失败或没有 HTML 时，访问事实仍然保留，原始页面引用为空；证据失败不能把已确认的 deny 改写成普通读取失败。

### 三、阈值异常继续是控制流异常

`ShopDenyExceeded` 和 `RoundDenyExceeded` 继续原样抛出，不转成普通商品级详情访问结果。异常关联统一形状的原始页面引用，删除当前在异常对象上动态附加 `raw_path` 的做法。

deny 账目、退避、阈值、重试次数、事件口径、失败记录、数据库提交和 deny 后果继续由 guard、点击路径和补采路径各自拥有。详情访问 module 不发领域事件。

### 四、页面关闭仍由打开页面的一侧负责

页面或弹窗继续由打开它的调用方关闭。统一结果不引入隐式关闭，也不改变成功、失败、deny、停止异常和 `popup_close` 的已有顺序。

### 五、迁移完成后删除旧形状

迁移点击路径后删除私有 `_LateDenied`，删除动态 `raw_path` 访问方式，不保留兼容 wrapper。生产调用方消费统一结果，详情观测调用方继续把访问事实映射为 `Observation` 与 `CaptureResult`。

## 结果与代价

- 点击采集与补采对一次详情访问拥有同一份可测试的结果和证据契约。
- 原始页面存档可以沿访问结果回指，但仍保持开发侧证据的边界，不进入交换集或销量分析输入。
- 详情观测 module 的业务职责不再被访问事实侵入；同日去重、机会、尝试、失败和提交规则继续可以独立演进。
- 阈值异常仍能中止店铺或轮次，同时保留与异常关联的统一证据引用。
- 结果对象增加最小引用和若干访问状态，测试面会扩大到证据成功、证据失败和异常路径；页面关闭、事件顺序与既有 deny 阶梯不变。

## 验收边界

本 ADR 的实现需要覆盖取得、初次 guard、可读等待、晚到 deny、晚到人工介入、当前页面读取失败、证据成功和证据失败。点击路径与补采路径只增加契约测试，锁定事件顺序、deny 后果、重试、页面关闭以及到 `Observation` / `CaptureResult` 的映射。

本 ADR 不改变 deny 阶梯、重试次数、详情预算、事件名称、数据库提交、详情观测规则或页面关闭责任。
