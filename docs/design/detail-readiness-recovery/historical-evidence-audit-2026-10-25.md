# 历史异常页面取证盘点（2026-10-25）

- Feature：`detail-readiness-recovery`
- 目的：根据 Q5 的决定，检查历史运行问题中是否存在同类“页面异常已被判定，但没有原始页面证据”的缺口。
- 范围：只盘点证据保存；不合并 deny 计数、deny 阈值、暂停语义、人工校验判定或浏览器归属问题。

## 结论

适合与本 feature 共用一套异常页面取证能力的历史问题有三组：

1. 详情页未就绪 / 页面上下文未知（本次 A09）：缺少失败页 HTML 和截图；
2. 滑块、登录墙、身份验证：已有“命中了人工介入”的事件或 HTML，但没有截图；
3. deny 拦截页：历史代码路径曾读到或能够取得原始 HTML，却没有落盘，且没有截图。

共同缺口是：页面状态异常时，后续控制流有记录，但开发者不能回看当时页面内容。共同能力可以只负责“尽力保存异常页面证据并关联事件”，不改变页面判定和后续处置。

## 纳入范围

| 历史问题 | 已有证据 | 缺口 | 是否纳入 | 约束 |
| --- | --- | --- | --- | --- |
| 2026-10-24 A09 详情页未就绪 | 日志、事件、状态；无 A09 HTML/截图 | 刷新前和最终失败点缺 HTML/截图 | 是 | 保存未知页面的每个恢复关键点；不能把证据保存失败变成新的暂停原因 |
| 2026-10-08 滑块反复失败 | 事件、日志、操作者描述；现场无截图，滑块页未存 | 页面视觉内容不可回看；判据来源需要与事件关联 | 是 | 只补证据，不改变响铃、人工等待、重试和暂停语义 |
| 2026-10-08 连续 deny 中止 | deny 事件、日志；拦截页没有原始 HTML，也没有截图 | 无法判断站点实际返回的拦截页形态 | 是 | 只补证据，不改变 deny 计数、阈值、降温或终止语义 |
| 2026-10-04 4 次 deny | deny 事件、日志；拦截页没有原始 HTML，也没有截图 | 与 2026-10-08 deny 相同 | 是 | 与上行共用保存能力；不单独扩展本 feature 的控制流 |
| 2026-10-24 deny 次数显示 0 | 有部分 slider HTML；deny 原始页缺失 | 另一个独立 issue 的计数与记录缺口 | 仅共享证据能力 | 不修改 deny 次数显示、`click_deny` 记账或首次降温期行为 |

“纳入”表示为后续 spec 评估共同的证据保存边界，不表示这些历史问题的全部行为都并入本 feature。

## 排除范围及理由

- 2026-10-04 人工校验触发时语音提示失效：已有 3 份原始 HTML；故障重点是声音路径，不是页面内容无法回看。没有截图属于一般采集缺口，不足以扩展本 feature。
- 2026-10-04 独立 profile 未登录仍继续：已有身份验证页 HTML；截图缺失，但页面正文已能支持判定分析，根因还涉及浏览器 profile 和登录状态。
- 2026-10-12 开始采集前读取浏览器事实超时：是启动前 PowerShell/浏览器事实读取问题，不是异常详情页。
- 2026-09 的测试、交换台和 GUI 问题：不是运行时详情页状态证据，不能与本 feature 共用同一领域边界。
- 已有详情解析失败 HTML 的路径：现有 `save_raw_page` 已有落点；若后续发现其关联信息不足，应作为实现时的完整性检查，不在本次历史盘点中另建控制流。

## 与既有 ADR 的冲突

[ADR-0057](../../adr/0057-intervention-archive-landing-and-boundary.md) 以前明确决定：滑块、登录墙、身份验证和 deny 保存 HTML，但不引入截图。Q5 按当前用户决定加入截图后，to-spec 必须明确这是对现有证据范围的调整，并决定：

- 截图是否覆盖本次未知页面、deny 和人工介入三类异常页面；
- 截图是否只在刷新前和最终失败点保存，还是人工介入命中时也保存一次；
- HTML 和截图的命名、关联事件、保存失败记录和体积限制；
- 是否同步修订 ADR-0057；
- 保存证据失败时只记日志，不能改变 deny、人工校验、跳过或暂停结果。

本盘点不修改 ADR，也不实施证据保存。
