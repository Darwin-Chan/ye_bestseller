# 固定配置 SKU 基线运行工具：第二步设计记录

日期：2026-10-24。阶段：grill-with-docs、to-spec、to-tickets 均已确认；implement 已完成工具、离线验证及分段全量收尾；全量2184项对账一致、1项弹窗环境断言失败，详见验证记录；真实模型未调用。

## 任务边界

本窗口准备独立研究工具、合成离线测试、使用说明和第三步执行方案。第一窗口负责真实样本、历史证据、分析日期和就绪清单；本窗口不修改其样本包、证据整理文件和报告。真实输入接入待第一步交接，不虚构分析日期或证据版本。

复用 ADR-0050、ADR-0060 与根领域词汇。候选输入仍由原样本包固定为 34 个候选集、536 个成员；候选集不是真实同款组。本轮不执行真实 LLM、不写运行数据库、不调参、不开始人工真值标注。保留其他任务的未提交改动，不替其提交、暂存、还原或清理。

## 已核实的生产行为

- 分析服务的 SKU 入口先恢复本地及共享人工约束，应用编码规则，再调用 SKU 图文判断；图文判断内调用候选推荐并刷新分组。
- SKU 判断和推荐通过生产 ModelWork 管理任务状态与缓存；默认缓存路径属于运行环境，研究工具必须显式换成独立研究缓存。
- ImageJudge 复用实际图文提示词、响应解析和视觉能力核验。视觉核验最多两次；判断与推荐分别构造 ImageJudge，核验调用本身也有成本。
- 请求层 ModelUsage 记录 compare/caption/verify 调用和供应商 token；recommend 在计数时归入 compare。SKU 流程未把完整请求账输出到研究报告，也没有费用账。
- 缺失 usage 不等于零 token。仅凭现有累计 token 无法构成完整预算账，研究工具需要保留逐请求使用量、缺失状态和费用来源。
- 当前配置为 direct、deepseek-flash、并发配置 2、candidates=6、min_score=4、timeout=30；请求层 temperature=0、JSON 响应格式。配置值必须在未来运行前冻结和核对，不能把本记录当作永久配置锁。
- SKU 判断当前逐对顺序执行；保留并发配置不意味着本工具擅自改造生产执行顺序。

## 用户已确认的七项决定

1. 候选集独立运行，每集仅使用自己的成员和候选语境；不跨集共享判断、推荐或视觉描述缓存。
2. 人工约束显式输入，不自动读取本机草稿或共享账本。第一步如提供适用的既有约束，经确认后冻结采用；没有提供则明确记录未采用人工约束。
3. 缺证据保留完整分母，不删成员、不借图。保留生产编码规则可得结果；受影响判断和推荐记为未完成，候选集不能标为完整完成。
4. 不由研究工具追加自动重试。保留生产视觉核验最多两次；请求失败、超时或证据不确定不自动重试。
5. 中断后显式续跑，仅在输入、配置、提示词与代码版本一致时复用完成结果；已发出而无可靠响应的请求待核对，不能悄悄重复付费。
6. 真实运行必须显式提供调用上限、预算上限及经确认定价表；数值留第三步确认。供应方未返回 token 记未知；费用估算和实际账单分开；无法可靠核算预算时暂停。
7. 每次产物、账本和独立缓存放在 .scratch/tool-output/sku-fixed-baseline-run/<run-id>/。不回填原 program_context.csv，真实运行后另行确认回填。

## 已确认的测试边界

以研究运行入口为主要验收边界：输入合成候选集、冻结配置、合成证据和模拟 HTTP 响应，检查持久化报告、成员结果、请求账、预算停止及续跑。保留生产编码、召回、ImageJudge 提示词与解析、ModelWork、推荐和组装逻辑；模拟层止于 HTTP 传输，不用模拟分组算法代替生产结论。预检查和离线模式必须无法访问真实服务。

复用现有 unittest 离线测试方式。定向测试后按仓库规范在隔离副本分段跑一次全量；副本只补入本任务点名文件，不混入其他任务未提交改动，证据写回主仓指定目录。

## 第一阶段补充的适用边界

第一窗口已明确研究目标为评价当前流程在完整输入下的分组效果。原包34集536成员尚未整体就绪，94条恢复同次图文输入也未通过完整观测和最终区间资格核验。工具当前保留已确认原包边界，不擅自重选样本或编造旧分析窗口。第三步先确认可取得的完整输入方案；若批准新版样本，另行修改边界校验及测试，再接入真实输入。


第一窗口补查的 [近期正式数据](../research/SKU近期正式数据运行条件核验-2026-10-24.md) 可支持研究新样本来源：2026-10-17有5,033个SKU及可关联图文材料，但生产取证仍缺原SKU观测。尚未冻结日期和新版样本，也未批准用同日流水重建输入。是否继续补源观测或接受保留来源限制的研究重建口径，属于第三步输入方案确认；本轮不改写真实样本门禁。
