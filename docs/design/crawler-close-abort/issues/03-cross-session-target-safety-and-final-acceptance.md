# 03: 跨入口采集与目标变化下的安全关窗，完成整体验收

Status: ready-for-agent

**What to build:** 用户关闭采集程序时，无论可识别的采集由当前界面、命令行还是先前界面启动，都得到相同策略。确认只授权原目标或明确暂停的轮次；目标变化时保留窗口并要求重新确认，原目标自然结束时保留真实终态。交付完整竞态与失败重试体验，并完成三票整体的 Windows 验收、测试证据及领域文档收口。

**Blocked by:** 02：所有暂停状态确认后升级为中止（01 为间接依赖）。

## Acceptance criteria

- [ ] 当前界面、命令行、先前界面启动的本机可识别采集遵循相同关窗确认、中止和等待收尾规则；不只处理当前 GUI 子进程，也不扩大现有中止入口的可识别目标范围。
- [ ] 可靠识别实际运行轮次，不用 GUI 遗留的旧轮次编号放弃另一轮；缺少本界面记忆状态时也不能把中止空操作成功视为关闭条件。
- [ ] 确认仅授权弹框时的进程目标或明确暂停轮次，进程身份结合 PID、启动身份与归属证明；同 PID 不同启动身份不视为同一目标。
- [ ] 弹框期间原目标被替换时，旧确认不作用于新目标，保留窗口、提示状态变化，并要求重新确认。新对话框对应当时真实状态，不叠加多个模态框。
- [ ] 确认后的停止或收尾等待期间出现新目标，也不扩张旧授权、不误停新采集、不静默自动关闭；保留窗口并提示需重新确认。窗口自身的开始与续跑守卫保持有效。
- [ ] 弹框期间原目标自然完成时保留真实终态，不因迟到的确认改成人工放弃；无新目标和待完成收尾时可关闭，有原收尾则等待其完成。
- [ ] 最终自动关窗前复核实际目标、终态和待完成收尾；完成旧目标中止不是忽略新目标的退出许可，不能把“无进程”单独当成已暂停证明。
- [ ] 目标暂不可核验、启动后尚无可靠身份、终态写入失败或强制停止失败时，窗口保留、原因可见、允许安全重试，既有核验与收尾继续驱动；不得绕过身份保护，不回滚已写入的人工放弃。
- [ ] 重试不会处置替换后的目标、重复中止或启动重复收尾；识别目标变化后须重新获取对应授权，原目标失败不能自动转移授权。
- [ ] 浏览器归属、借用浏览器保留、有限重试与条件清理规则在跨入口和目标替换场景中保持有效，不处置用户或新目标的无关浏览器。
- [ ] 在已确认的高层关窗集成入口覆盖跨会话、旧 GUI 轮次记忆、确认中自然结束、确认中替换目标、等待中替换目标、PID 复用、不可核验身份、停止失败与安全重试；适用场景同时覆盖采集中和明确暂停路径。
- [ ] 回归 01、02 及父规格完整矩阵：暂停三阶段全部确认、取消保持原行为、已中止不重复停止、完成或未开始直接关闭、失败不静默退出、数据与终态保护全部满足。
- [ ] 完成 Windows 人工验证并记录结果：×、Alt+F4、任务栏关闭、不同页面、默认取消、关闭确认框、真实阶段中文文案、等待时界面响应及自动关闭。不得将模拟集成测试当成原生交互验证；未验证项明确标注待验收，不伪报通过。
- [ ] 最终按项目规范在隔离副本串行分段跑一次全量测试，证据保存在主仓票证据位置，记录各段日志及合计、对账、结论；不使用提前停止参数替代收尾全量，不以仅跑长尾文件为全量。
- [ ] 根据已实现且验证的行为同步领域上下文及旧 ADR 的关窗政策替代说明；保留历史依据、双锁和身份保护，不把待实现规则写成已运行事实，不覆盖无关工作区修改。
- [ ] 关闭本票前按隔离副本与证据收尾规范记录主仓、副本、证据和保留/可删除候选/暂留待确认清单；未创建或无产物时明确记录。删除候选不等于删除授权，不自行清理目录。

## Boundaries and handoff

- 父规格为本功能目录中的《采集程序正常关窗：确认、中止本轮并等待收尾》，遵循 ADR-0048；保留 ADR-0008 的双锁与身份登记、ADR-0009 的协作停止，以及 ADR-0024、ADR-0028 的目标与归属保护，只替代冲突的关窗后后台继续政策。
- 本票依赖 02，因为目标授权与变化需同时集成采集中和明确暂停路径，整体验收必须覆盖两票成果；01 通过 02 间接阻塞，无须重复列独立边。
- 本票不是纯测试票：必须交付跨入口识别及确认、等待、重试期间目标变化的完整用户行为，再做整体验收与文档收口。
- 不重做全局异常恢复、轮次模型或进程发现，不扩大强制停止和浏览器清理权限，不改变其他程序关窗政策，不保证任务管理器强制结束或断电等非正常关闭。
- 人工验证涉及的环境、数据和真实采集另行遵守运行授权，不因本票就绪擅自启动正式采集。
