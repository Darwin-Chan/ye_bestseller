## 01: 采集停止、暂停与收尾提示展示实际原因

**What to build:** 从用户暂停、中止、关窗或采集异常，到请求、进程输出、开始/过程/结果页和收尾提示，说明本次实际原因并给出所属入口允许的下一步。

**Blocked by:** None (can start immediately).

**Status:** done

**Coverage:** C1–C4、D1–D8、F1–F2、G1–G2，共 16 项；A1–A4、B1 回归

- [x] 同一明确暂停在静态/动态横幅、开始页单轮/多轮摘要和关窗阶段提示中都显示由用户主动暂停。
- [x] 暂停、中止及确认关窗的实际来源在停止和重试收尾期间保留，暂停与中止不再共用错误的暂停输出；未知来源显示未记录。
- [x] 原始停止原因与进程核验、强制停止或浏览器关闭的收尾失败原因分别展示，原停止目标不随进程更换改变。
- [x] 异常原因只含阶段、店铺和故障事实；GUI 与命令行各自补充操作建议，未开放 GUI 异常停机续跑。
- [x] 继续受阻与继续启动失败保留原有原因和暂停资格说明；关闭专用 Edge 不自动继续。
- [x] 启动失败显示对应本轮可靠详情；未知终态显示非正常结束和可靠原因或未记录。
- [x] 即将跨天的命令行提示明确本轮中止、0 点后开始新轮；两处确认标题统一使用中止。
- [x] 滑块/登录墙超时、跨执行旧原因隔离和失败率超限终态文案保持已验收行为。
- [x] 经真实临时数据库、GUI 动作/页面读数与 HTML 横幅，以及采集入口操作者输出验证；暂停资格、终态、停止时限、目标绑定和浏览器归属规则保持。

## 02: 匹配等待、摘要与未完成任务展示停止来源

**What to build:** 点击停止匹配或确认关窗后，等待框、完成摘要、商品对与 SKU 未完成任务显示同一可靠来源，并保持停止后可以继续补判。

**Blocked by:** None (can start immediately).

**Status:** done

**Coverage:** E1–E5，共 5 项

- [x] 按钮停止与确认关窗分别携带实际来源；既有不携带来源的调用兼容，来源缺失显示未记录。
- [x] 同次运行重复停止请求不覆盖第一次已确认来源；新运行或重试不继承上一趟停止原因。
- [x] 等待框和停止后摘要展示停止原因、完成数量和当前超时；存在可重试项时沿用现有建议条件。
- [x] 商品对未完成说明和 SKU 停止任务说明显示可靠原因，未知旧记录不写成用户主动停止。
- [x] 未判断的商品对仍是可重试失败，既有状态文本与旧草稿仍能识别；SKU 已有任务状态和重试分类保持。
- [x] 分析运行的来源只随既有运行读数传递，不新增跨机运行进度或持久化停止标志。
- [x] 已判断缓存、未完成项补判、在途调用处理和终态后无写入契约保持；商品与 SKU 各自已有停止行为保持。
- [x] 通过真实分析服务、可控假模型和真实本地 HTML 页面验证按钮及关窗来源、缺失兜底、旧记录和重试兼容。
