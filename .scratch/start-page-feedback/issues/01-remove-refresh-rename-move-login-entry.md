**What to build:** 开始页页头右上角出现「打开专用 Edge」按钮（在「进入本机试采」左边，仅开始页签显示）；全页删除「刷新浏览器状态」按钮（HTML 与绑定一并删）；开始卡只保留浏览器事实行与说明文字。全仓不再出现指向该按钮的「点刷新」指示：浏览器 facts 的 retry 文案与开始卡说明句改为自动核对口径（「确认退出后再开始采集（界面会自动核对）」一类同义句，措辞要让开始页与过程页两处同源显示都读得通）。过程页同文本按钮「打开专用 Edge / 登录 1688」一并改名「打开专用 Edge」，行为不变。原有的自动核对时点（进页、切回开始页签、切换试采）全部保留——删按钮不等于减少核对。本票只动位置、名字与文案，**不动任何禁用投影与点击逻辑**（那是 02 的事）。

- [ ] 开始页签：页头右侧依序为「打开专用 Edge」「进入本机试采」；开始卡内不再有登录入口按钮，也不再有刷新按钮。
- [ ] 非开始页签（过程/结果）不显示页头「打开专用 Edge」按钮；过程页自有的登录入口卡片照旧显示（仅名字变化）。
- [ ] 过程页登录入口文案为「打开专用 Edge」，其可用性/禁用/提示行为与改名前逐项一致（只有文案变化）。
- [ ] 全仓无「刷新浏览器状态」残留；不再有「点刷新」类指示（含 `dedicated_browser.RETRY` 与开始卡说明句）。
- [ ] 自动核对时点不变：进页取一次事实；切回开始页签、切换试采后事实行随之更新（页面用例断言）。
- [ ] 受影响的既有测试接缝成对更新：`tests/test_manual_edge.py` 中以点击 `#refreshBrowserBtn` 充当刷新触发的用例改用等价触发（如直接走取数链），断言意图不变。
