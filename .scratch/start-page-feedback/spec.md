## Problem Statement

开始页把「主动核对」的负担交给了用户：

1. 「打开专用 Edge / 登录 1688」与「开始抓取」在**浏览器检测**结果不满足时被预先置灰（专用 Edge 已占用、状态无法确认、打开失败、调试端口被无关实例占用、正在打开，以及缺 Edge/配置错误/外部连接模式）。用户看到灰按钮不知道为什么、也不知道是否自己能修——现场体验就是「点击不了」。
2. 已占用时点「打开专用 Edge」没有任何弹框反馈（只默默刷新事实行），用户以为按钮坏了。
3. 「刷新浏览器状态」按钮要求用户手动管理一场本应自动的核对；它的存在还让说明文案不得不写「再刷新并明确开始采集」。
4. 按钮名「打开专用 Edge / 登录 1688」在字面上替界面暗示了登录状态，与「界面绝不宣称账号已登录」的既定口径有张力。
5. 登录入口的位置（开始页卡片内）与试采开关（右上角）分居两处，日常动线别扭。
6. 过程页的登录入口埋在「暂停后处理登录」卡片里，与页头试采开关分居两处；开始页入口上移后，两页动线更不一致（v2 提出）。
7. 「改范围（中止后重选）」与「中止本轮（放弃）」两个按钮都中止原轮、后缀都在讲重选/放弃，读起来困惑；改范围本就可以走「中止 →（收尾）→ 回开始页重选 → 明确开始」（v2 提出）。

## Solution

- **删**「刷新浏览器状态」按钮。
- 「打开专用 Edge / 登录 1688」**改名「打开专用 Edge」**，移到右上角、「进入本机试采」左边（开始页与过程页两处同文本按钮一并改名）。
- 两个按钮不再因**浏览器检测类**（已占用/无法确认/打开失败/端口被占/正在打开）与**配置错误类**（缺 Edge/坏配置/外部连接模式）预置灰：按钮亮起；点击时自动核对（「开始抓取」先取一次最新开始页事实），不能执行就弹**页面内信息框**（与现有确认弹窗同壳、单按钮「知道了」）说明原因。示例：「专用 Edge 已被打开，请手动关闭（包括后台窗口）后，再开始抓取」；已占用时点「打开专用 Edge」→「专用 Edge 已在运行，请用原窗口；登录后请关闭它再开始采集」。
- **维持现状置灰**（不动）：计划未就绪/正在确认（唯一的历史置灰，勾选按钮联动）；纯汇总机·正式模式（两个按钮）；采集中、停止收尾进行中；未结束轮次（遗留/跨天/范围冲突）；收尾欠账未结清。对应的提示文案与处置卡（「中止此轮」「重试收尾核验」、过程页「继续」等）一律照旧。
- **试采不置灰**：「打开专用 Edge」在纯汇总机的本机试采下可用（共用同一份专用 profile，登录准备本就必需）——继承票 08（e2cee2c）口径并在本批保留。
- **（v2）过程页按钮收整**：
  - 过程页「打开专用 Edge」入口上移页头，与开始版占同一横向槽位、按页签互斥显示（过程页签有轮次才显；结果页签不显）；「暂停后处理登录」整卡删除（含浏览器事实行与说明文字）。
  - 报因扩到过程页：入口沿用同样的「检测/配置类亮起点击报因、忙/资格类维持置灰（理由挂悬浮提示）」切法；「继续」不再因门禁置灰，点击弹信息框给原样原因。
  - 删「改范围（中止后重选）」：改范围＝中止＋重选（Q8 语义不变），动线为「中止本轮 →（等收尾）→ 结果页『返回开始』→ 重选 → 明确开始」；不加替代按钮、不加教学旁注。
- 服务端授权与拒绝语义**一行不改**；本批只改前端禁用投影与点击流程。

## User Stories

1. As a 采集用户, I want 开始页的「打开专用 Edge」按钮在右上角、紧挨试采开关, so that 我的日常动线（登录准备→开始）在同一区域完成。
2. As a 采集用户, I want 按钮只叫「打开专用 Edge」, so that 界面不替账号状态说话（登录与否由我自己在专用窗口里核对）。
3. As a 采集用户, I want 专用 Edge 已占用时点「打开专用 Edge」得到明确提示框（已在运行、请用原窗口、关闭后再开始）, so that 我不会以为按钮坏了，也不会重复开第二个窗口。
4. As a 采集用户, I want 专用 Edge 已占用时点「开始抓取」被明确告知「请手动关闭（包括后台窗口）后再开始抓取」, so that 我知道一步就能修好，而不是对着灰按钮猜。
5. As a 采集用户, I want 浏览器状态无法确认/打开失败/调试端口被无关实例占用时按钮仍是亮的、点击弹框给出安全拒绝说明与重试指引, so that 界面如实、可操作，且绝不显示假的「已关闭」、不接管无关浏览器。
6. As a 采集用户, I want 缺 Edge/配置错误/外部连接模式时点击任一按钮弹框告诉我配置怎么改, so that 我在本机就能修好，不用敲命令。
7. As a 采集用户, I want 不再有「刷新浏览器状态」按钮：我进页面、切回本页、点两个按钮时界面自动核对最新事实, so that 我不用手动管理核对节奏。
8. As a 采集用户, I want 计划没就绪时「开始抓取」保持置灰并附「重试准备」, so that 「拿不准的时候不开轮」的既有行为不变。
9. As a 采集用户（试采）, I want 忘勾店铺时点开始得到一个提醒框, so that 提示样式与其它报因一致。
10. As a 采集用户（纯汇总机·正式模式）, I want 两个按钮维持置灰, so that 我清楚这台机器不做正式采集（点它也没意义）。
11. As a 采集用户（纯汇总机·试采）, I want 「打开专用 Edge」亮起且能开, so that 我在 m4 上也能为试采准备同一份专用 profile 的登录。
12. As a 采集用户, I want 采集中、停止收尾中、遗留轮待处置、收尾欠账未结清这些时刻维持现状（置灰+文案+处置卡）, so that 程序自己在忙或在等你处置时，行为和你已经熟悉的现在一致。
13. As a 采集用户, I want 一切被拒绝的提示都是页面内的信息框（「知道了」），不是系统弹窗, so that 界面风格统一、不突兀。
14. As a 采集用户, I want 正常路径不受打扰：计划就绪、专用 Edge 未开、勾好店铺→点开始直接进入采集, so that 常亮不等于多打扰。
15. As a 采集用户, I want 关掉再开界面时（轮次还在跑）看到照旧的「已有采集在跑」提示与处置入口, so that 重开/异常恢复的认知不变。
16. As a 采集用户, I want 过程页的登录入口可用性资格与现在完全一致（只在明确暂停且收尾完成后可用，占用提示、继续门禁照旧）, so that 暂停后的手动处理流程零变化（v2 修订：入口位置、报因口径与卡片形态按故事 21–27 收整；可用性资格仍按本句）。
17. As a 维护者, I want 服务端授权（`start_run`/`open_login_browser` 的门禁、拒绝文案、试采/角色判定）一行不改, so that 这次只是「界面投影与点击流程」变化，权限模型不动。
18. As a 维护者, I want 浏览器检测类从「前端禁用」改为「点击报因」后，测试与验收语言成对更新（计划锁/角色/忙状态等格原样不动）, so that 保护意图（不误开、服务端仍拒绝、原因准确）逐条保留。
19. As a 维护者, I want 去「刷新」字样时文案同源修改（浏览器事实的 retry 文案、开始卡说明句）, so that 界面里不再出现指向已删除按钮的指示。
20. As a 维护者, I want 本 spec 与 issues-08-11 母 spec 的关系记录在案（可用性表脚注的「受机器角色约束」在正式模式不变；试采格以票 08 口径为准）, so that 两份文档不互相矛盾。
21. As a 采集用户, I want 过程页的「打开专用 Edge」也在页头同一位置（有轮次时可见）, so that 两页动线一致，不用两处找入口。
22. As a 采集用户, I want 过程页签没有轮次时不显示该入口, so that 没有可处理的东西时页头干净。
23. As a 采集用户, I want 过程页入口在浏览器检测/配置类异常时亮起、点击弹框说原因, so that 与开始页口径一致，且我能动手修好（关窗口/改配置）。
24. As a 采集用户, I want 采集中/验证等待/停止收尾中等忙态与资格未具备时该入口仍灰、悬浮提示给出原因, so that 程序自己在忙或还没到可处理时机时不摆假动作。
25. As a 采集用户, I want 暂停后「继续」不再因占用/配置等原因灰着, so that 我点一下就能听到为什么还不能继续。
26. As a 采集用户, I want 「关闭窗口不会自动继续本轮」这句话仍然能看到（暂停横幅里）, so that 我不会干等自动恢复。
27. As a 采集用户, I want 只有一个中止按钮（「中止本轮」）, so that 不再对着两个都叫中止的按钮猜；换范围走「中止本轮 → 回开始页重选 → 明确开始」。
28. As a 维护者, I want 删「改范围」只删前端捷径、服务端与 Q8 路径语义一行不改, so that 保护意图（改范围＝确认中止＋收尾＋重选＋明确开始）逐条保留。

## Implementation Decisions

- **前端禁用投影**（两个按钮）：
  - 「开始抓取」的置灰来源 = 计划锁 + 纯汇总机·正式 + 采集中 + 停止收尾中 + 未结束轮次/范围冲突 + 收尾欠账（即现状的全部，**减去浏览器/配置门禁那一半**）。
  - 「打开专用 Edge」的置灰来源 = 关闭中 + 服务端拒绝（采集/等待/停止收尾/欠账）+ 纯汇总机·正式（试采除外）；**减去浏览器检测与配置错误**。
  - 「正在打开」的瞬时态不再置灰（服务端 `reserve_open` 去重与 `reused` 返回已能防双开）。
- **点击流程**：
  - 「开始抓取」：点击 → 走既有取数链取一次最新开始页事实（一条在途刷新之内）→ 若存在浏览器/配置门禁原因或开始提示 → 信息框（原因优先级：浏览器/配置门禁文案 → 开始提示文案）；否则调用既有开始 API（其服务端拒绝仍照旧，失败也走信息框）。
  - 「打开专用 Edge」：点击 → 直接调用既有公开 API（其返回已含精确原因与「已有窗口」标志）→ 失败弹信息框（原因原样）；`reused`（已在运行/正在打开）弹「已有窗口」信息框；成功则刷新事实行。
- **信息框**：页面内模态的确认弹窗壳加一个单按钮信息变体（复用现有 modal 结构，隐藏取消、按钮文案「知道了」）；所有本批新增的点击报因与「未勾选店铺」提示统一用它。
- **布局**：页头右侧改为一个横向容器，顺序为「打开专用 Edge」→「进入本机试采」；开始页原卡片保留事实行与说明文字。
- **文案同源修改**：浏览器事实的 retry 文案与开始卡说明句去掉「刷新」字样（改为「关闭后再开始采集（界面会自动核对）」一类的同义句）；「刷新浏览器状态」按钮的 HTML/绑定删除。
- **不新增轮询**：开始页仍不轮询；事实刷新时点 = 进页、切回开始页签、试采切换后、两个按钮点击时（与删除前的集合等价）。
- **试采豁免**：纯汇总机·试采下「打开专用 Edge」不因角色置灰（继承 e2cee2c）；本批新增的浏览器检测亮起同样适用于试采。程序忙/收尾欠账等格在试采下仍按现状置灰（待实现前最终确认）。
- **改名范围**：开始页与过程页两处同文本按钮统一改名为「打开专用 Edge」。
- **（v2）过程页按钮收整（票 04）**：
  - **形态**：两枚按钮元素（开始版/过程版）放页头同一横向容器、占同一视觉槽位，按页签互斥显隐（开始页签显开始版、过程页签显过程版、结果页签都不显）；不合并为单元素。
  - **显隐与卡片**：过程版在有轮次（has_round）时显示；「暂停后处理登录」整卡删除，过程页不再渲染浏览器事实行（开始页事实行与说明文字保持 v1 交付原样）。
  - **置灰/报因划分**：非浏览器检测类（采集中/验证等待/停止收尾中/未具备暂停资格/收尾欠账等服务端拒绝类）保持现状置灰、原因挂按钮悬浮提示；检测类与配置错误类亮起、点击弹单按钮信息框（复用票 02 的壳）。
  - **「继续」报因**：can_resume 时显示、不再因 continue_gate 置灰；点击直调既有 resume_run（服务端为权威检查），失败弹信息框原样原因；暂停横幅照旧讲状态，「关闭窗口不会自动继续本轮」句迁入横幅。
  - **删「改范围」**：前端整链删除（按钮、禁用行、changeScope 与自动回开始页机制、doAbort 的 changeRange 形参、绑定）；prepare_abort/confirm_abort 两个 API 保留（中止本轮/遗留轮处置共用）；替代动线＝中止本轮 → 结果页「返回开始」→ 重选 → 开始；不加替代按钮与教学旁注。
  - 服务端授权与拒绝语义一行不改（同 v1）。

## Testing Decisions

- **接缝**：沿用本线已确认的第一组高层接缝（实际页面事件 → 真实 Api/配置/视图/临时 SQLite；只适配浏览器 OS 事实与时钟）——本批是页面交互 + 服务端投影，接缝沿用、不新造。
- **好测试的判据**：断言用户可观察行为——点击后信息框出现且文案为同源拒绝原因；被拒绝时不误开（启动/接管计数为零）；保持置灰的格（计划锁/角色/忙状态/遗留/欠账）在页面上仍为灰、断言原样保留；服务端拒绝路径不变。
- **落点与先例**：`tests/test_manual_edge.py`（入口门禁与页面点击流的既有先例）、`tests/test_ui_live.py`（页面事件先例）、`tests/test_local_trial_gui.py`（试采夹具先例）、确认弹窗相关既有用例（信息框变体）。受影响的既有断言按 Story 18 成对更新。
- **（v2）票 04 接缝**：沿用同一组高层接缝与信息框壳（壳由票 02 交付，04 复用、不新造）；成对更新清单——`tests/test_paused_manual_login.py`（事实行断言改信息框断言）、`tests/test_joint_acceptance.py`（J-A01 同）、`tests/test_explicit_pause_resume.py`（改范围用例改走「中止本轮」＋「返回开始」）、`tests/test_manual_edge.py`（页头槽位与显隐接缝扩展）。
- **全量**：按仓库收尾口径在隔离副本跑分段全量并留证。

## Out of Scope
