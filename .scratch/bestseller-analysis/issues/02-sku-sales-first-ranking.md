# 02: 按 SKU 计算销量并查看初步排名

Status: resolved

**Parent:** [异步畅销品分析规格](../spec.md)

**What to build:** 用户在固定数据中看到正确的 SKU 与商品销量，逐个确认独立组后进入初步畅销品排名，并展开基本库存／累计销量图。此票打通计算到可见结果，后续同款合并复用同一计算结果。

**Blocked by:** 01 — 选择日期并固定一次分析。

**规格依据：** Implementation Decisions 4—6、10、14 的基础路径；A01—A08、A28，A39 的进入资格部分。

- [x] 使用库存值构建 SKU 逐日序列，不直接求和现有库存差分；比较身份含店铺、商品、SKU。
- [x] 开始日只作基准，销量及累计销量为 0；只统计后续相邻日直到结束日。
- [x] 起点缺失时先找之前最近观测，没有时找后续首笔建立基准；中间缺失向前填充，缺失日不均摊销量。
- [x] 真正的库存 0 与未知区分；没有基准时不构造销量。首次观测不与其他 SKU 比较。
- [x] 每 SKU 销量先取非负下降量再汇总；100→80 与 50→90 的两个 SKU 汇总销量为 20，不是 0。
- [x] A02 的库存序列区间销量为 40；A04 起点前填后的销量为 10；A05 首笔后填基准到末尾累计为 10。
- [x] 输出真实／填充状态、疑似补货、每日库存及累计销量，页面基本图表正确使用；SKU 缺失为黄、增加为红，上层只按是否存在补货决定红／绿，正常点无 hover。
- [x] 确认页单商品组包含零销量商品；单独确认立即更新人工状态，不弹重复确认框。未全部确认时不能进入正式结果。
- [x] 全部确认后能查看按商品销量降序的初步结果及基本明细；此时每组一个商品，不把尚未交付的跨店识别宣称为完成。
- [x] 初步结果支持当前阶段的库存与累计销量结果展示、折叠明细，不新增父规格已删除的每日计算弹窗、商品重复图或 SKU 图片；后续只扩充同款构成及图表可读性。
- [x] 用浏览器走选日期、逐组确认、打开结果并核对图及数值；高密度数值边界补充服务集成验证，使用手算期望值。

**演示路径：** 选择 7—14 日 → 查看含缺失与补货的商品 → 单组确认 → 排名 → 展开 SKU 图核对 40 件销量。

**边界：** 本票计算单一规格形态的连续有效段，多次形态切换由 03 扩充。正式持久保存按钮与恢复由 08 交付，之前不得显示虚假的“保存成功”；初步结果路径不视为已持久保存。
